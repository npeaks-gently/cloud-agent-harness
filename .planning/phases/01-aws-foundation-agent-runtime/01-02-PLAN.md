**src/cloud/daytona-client.ts** -- Daytona SDK wrapper. Follow the GSDTools service class pattern: class with constructor taking options object, private readonly fields, custom error class, typed convenience methods.

```typescript
export class DaytonaError extends Error {
  constructor(
    message: string,
    public readonly operation: string,
    public readonly sandboxId?: string,
  ) {
    super(message);
    this.name = 'DaytonaError';
  }
}

export class DaytonaClient {
  private readonly apiKey: string;
  private readonly target: string;

  constructor(opts: {
    apiKey: string;
    target?: string;
  }) { ... }

  async executeTask(config: AgentTaskConfig): Promise<AgentTaskResult> { ... }
}
```

The `executeTask` method:
1. Creates a Daytona instance: `new Daytona({ apiKey: this.apiKey, target: this.target })`
2. Creates a sandbox: `daytona.create({ language: 'typescript', envVars: config.envVars })` with optional resources `{ cpu: config.resources?.cpu ?? 2, memory: config.resources?.memory ?? 4 }` (2 vCPU / 4GB per Pitfall 5)
3. Clones the repo: `sandbox.git.clone(config.repoUrl, '/home/daytona/workspace', config.branch)`
4. Executes the command: `sandbox.process.executeCommand(config.command, '/home/daytona/workspace', config.envVars, config.timeoutSeconds ?? 300)`
5. Returns `{ exitCode: response.exitCode, stdout: response.result, durationMs }` (measure duration with `Date.now()`)
6. Always deletes the sandbox in a `finally` block: `await sandbox.delete()` (per D-07, prevents runaway costs per Pitfall 1)
7. Wraps all errors in `DaytonaError` with operation name and sandbox ID when available

`SqsConsumer` class:
```typescript
export class SqsConsumer {
  private readonly client: SQSClient;
  private readonly queueUrl: string;
  private readonly waitTimeSeconds: number;

  constructor(opts: {
    queueUrl: string;
    region?: string;
    waitTimeSeconds?: number;
  }) {
    this.client = new SQSClient({ region: opts.region ?? 'us-east-1' });
    this.queueUrl = opts.queueUrl;
    this.waitTimeSeconds = opts.waitTimeSeconds ?? 20;
  }

  async receiveMessage(): Promise<{ message: PipelineJobMessage; receiptHandle: string } | null>
  async deleteMessage(receiptHandle: string): Promise<void>
}
```

The `receiveMessage` method:
1. Sends `ReceiveMessageCommand` with `MaxNumberOfMessages: 1`, `WaitTimeSeconds: this.waitTimeSeconds`
2. If no messages, returns `null`
3. Parses message body as JSON
4. Validates it has required fields (`projectId`, `repoUrl`, `branch`, `featureDescription`) using a type guard function `isPipelineJobMessage(body: unknown): body is PipelineJobMessage`
5. Returns `{ message: parsedBody, receiptHandle: msg.ReceiptHandle }`
6. Wraps errors in `SqsConsumerError`

The `deleteMessage` method: Sends `DeleteMessageCommand` with the receipt handle.

Type guard function:
```typescript
function isPipelineJobMessage(body: unknown): body is PipelineJobMessage {
  if (typeof body !== 'object' || body === null) return false;
  const obj = body as Record<string, unknown>;
  return (
    typeof obj.projectId === 'string' &&
    typeof obj.repoUrl === 'string' &&
    typeof obj.branch === 'string' &&
    typeof obj.featureDescription === 'string'
  );
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Application code -> Daytona API | API key authenticates; sandbox operations are privileged |
| Application code -> RDS (public internet) | Database credentials over SSL; all queries must be parameterized |
| Application code -> S3 | AWS credentials for artifact read/write |
| SQS message body -> Application parser | Untrusted input from message producers must be validated |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | postgres-client.ts SQL queries | mitigate | All queries use parameterized placeholders (`$1`, `$2`); no string interpolation in SQL; dynamic SET clause builds parameterized list |
| T-02-02 | Information Disclosure | postgres-client.ts connection | mitigate | SSL enforcement via `ssl: { rejectUnauthorized: true }` on every connection; connection string from Secrets Manager, not hardcoded |
| T-02-03 | Tampering | sqs-consumer.ts message parsing | mitigate | Type guard `isPipelineJobMessage()` validates all required fields are present and correctly typed before processing; invalid messages throw SqsConsumerError |
| T-02-04 | Spoofing | daytona-client.ts API key | mitigate | API key injected via constructor from environment variable, not hardcoded; stored in Secrets Manager (provisioned by Plan 01) |
| T-02-05 | Denial of Service | daytona-client.ts sandbox leak | mitigate | Sandbox deletion in `finally` block guarantees cleanup on success, failure, and timeout; prevents runaway sandbox costs |
| T-02-06 | Information Disclosure | s3-artifacts.ts data integrity | mitigate | SHA256 checksum on PutObject via `ChecksumAlgorithm: 'SHA256'`; detects corruption in transit |
</threat_model>
